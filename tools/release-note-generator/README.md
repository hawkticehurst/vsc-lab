# Social Asset

A simple HTML + CSS tool for creating VS Code release note graphics for social media.

## Usage

```bash
# From the workspace root
pnpm --filter social-asset dev

# Or from this directory
pnpm dev
```

Then open http://localhost:5173 in your browser.

## Features

- Dark themed release card design
- Month/version header with VS Code branding
- Three-column layout for feature categories
- Each feature includes a title and description

## Customization

Edit `index.html` directly to change:
- Release month and version number
- Column titles
- Feature names and descriptions

## Screenshot

Take a screenshot of the rendered page to create your social media asset.
